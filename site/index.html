機能

シンプルに、もっと効率よく。

タスク管理の本質に集中した機能セット。複雑さを排除し、日常の報告作業を省力化します。

🎯

タスクの一元管理

Notion・Google スプレッドシートに分散したタスクをひとつの画面で確認・更新。ツールを横断した「自分ビュー」を実現します。

🔄

リアルタイム同期

Supabase Realtime により、PC・スマホ間のデータが即座に同期。どのデバイスで更新しても、すべての画面に反映されます。

📝

日報・作業報告の自動生成

テンプレートと差し込み変数で日報を 3 ステップで生成。クリップボードや Markdown ファイルとして出力できます。

🗂️

プロジェクト階層管理

プロジェクト → リスト → タスク → サブタスクの 4 階層で整理。ステータス・進捗度・優先度・作業時間を一元管理します。

🔐

セキュアな設計

API トークンや OAuth 認証情報は Supabase Vault（pgsodium）で暗号化保管。Magic Link 認証と ALLOWED_EMAILS による個人限定アクセスを実現します。

🌐

マルチデバイス対応

Next.js App Router による高速レンダリングでブラウザからアクセス。インストール不要で PC・スマホ・タブレットから同じ体験を提供します。

日報生成

日報を、3 ステップで。

テンプレートと差し込み変数でレポートを瞬時に生成。タスクデータが自動で埋まります。

テンプレート — 業務日報
【{{date}}業務報告】
■今日やったこと: 計{{today.totalHours}}h
{{today.workLog}}

■勉強になったこと


■明日やること
{{next.tasks}}

■連絡事項
1
テンプレートを選ぶ
「作業開始報告」「業務日報」など用途に合わせたテンプレートを選択。自分専用のテンプレートも作成できます。
2
「生成」を押す
今日の作業ログ・進行中タスク・明日の予定が自動で差し込まれてプレビューに表示。手動で微調整することも可能。
3
コピーして送信
クリップボードにコピーしてそのまま貼り付け、または Markdown ファイルとして保存。レポート履歴に自動保存されます。

差し込み変数

12 種類の変数で、何でも書ける。

クリックするだけでカーソル位置に挿入。シンタックスを覚えなくても自由にテンプレートを作れます。

{{date}}生成日
{{today.totalHours}}今日の合計作業時間
{{today.workLog}}今日の作業ログ（工数付き）
{{today.plan}}今日の予定タスク一覧
{{today.completed}}今日完了したタスク
{{today.inProgress}}今日作業中のタスク
{{assigned.tasks}}担当タスク一覧（進捗%付き）
{{next.tasks}}次にやるタスク（期限順）
{{projects.summary}}プロジェクト別進捗サマリー
{{period.completed}}期間内に完了したタスク
{{period.start}}対象期間の開始日
{{period.end}}対象期間の終了日
